# AdGuard Home 规则聚合器

自动聚合多个广告拦截规则列表，每天更新，在 AdGuard Home 中只需要添加一个 URL。

## 使用方法

### 1. 在 AdGuard Home 中添加过滤器

```
https://raw.githubusercontent.com/gewasli/adg-rules-aggregator/main/dist/rules.txt
```

### 2. 规则源

- EasyList
- EasyList China
- anti-AD
- EasyPrivacy
- uBlock Ads / Privacy
- urlhaus 恶意软件防护
- GOODBYEADS DNS
- hagezi Multi Pro
- OISD Big
- AdGuard 中文过滤
- 1Hosts Pro

### 3. 更新频率

每天 UTC 0:00（北京时间 8:00）自动更新一次。
